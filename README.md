# Покерный калькулятор Soft Егора

Покерный калькулятор, адаптированный и переименованный для проекта «Soft Егора».

## Запуск

Откройте `index.html` в браузере. Установка зависимостей не требуется.

## Авторство

Проект основан на публичном репозитории
[shurikshilkin/calculator](https://github.com/shurikshilkin/calculator).
История исходного репозитория сохранена. Изменены название и оформление бренда.
